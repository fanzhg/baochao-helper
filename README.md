# 爆炒江湖 · 百味楼 & 每周厨神大赛配队助手

一款开箱即用的《爆炒江湖》本地配队求解工具，支持通过**白菜菊花校验码**一键同步个人账号数据（厨师、修炼、厨具、遗玉、心法盘、菜谱专精），提供：
- **《百味楼》0 误差校准配队引擎**：支持多楼层内置/新增、一键全算、不换厨具最高分 & 换厨具极限冲榜；
- **每周厨神大赛 & 限时活动关求解器**：自动拉取白菜菊花最新图鉴库与当周厨神全分段规则（村级 ~ 御前），精确分配 3 厨 × 3 菜与份数。

> 数据来源与算分逻辑对齐白菜菊花图鉴（`h5.baochaojianghu.com` / `i.baochaojianghu.com` / `yx518.com`）。

## 两种使用方式（任选其一）

### 方式一：绿色免安装 `.exe`（推荐 · 无需安装 Python）
适合任意 Windows 电脑（哪怕完全没装过 Python）：
1. 前往本仓库右侧 **Releases**（或 Actions 产物）下载 **`爆炒江湖配队助手.exe`**。
2. 将 `.exe` 放到任意空文件夹中，**直接双击运行**。
3. 首次启动会自动联网下载最新图鉴库和当周规则（并在同目录生成 `data/` 文件夹保存你的账号缓存与新增楼层），同时自动在浏览器打开 `http://127.0.0.1:8765/`。
   * *提示：若 Windows Defender 弹出未知发布者提示，点击「更多信息 → 仍要运行」即可；或自行使用方式二源码运行/打包。*

### 方式二：源码直接运行（需 Python 3.9+，零第三方依赖）
不需要 `pip install` 任何第三方包，仅使用 Python 标准库：
1. 下载本仓库（`git clone` 或点击 `Code → Download ZIP` 解压）。
2. Windows 直接双击 **`启动爆炒助手.bat`**（或在终端执行 `python app.py`）。
3. 浏览器自动打开 `http://127.0.0.1:8765/`。

## 使用指南

### 1. 加载与切换账号（支持多账号）
1. 在《爆炒江湖》游戏内点击左上角头像 → **设置** → 复制 **白菜菊花校验码**（6 位字母，如 `DVMVGD`）。
2. 在网页顶部输入框粘贴校验码，点击 **「加载账号」**，工具会自动同步该账号的厨师、修炼、菜谱专精与厨具/遗玉配置并缓存在本地 `data/` 目录。
3. 换另一个账号时，直接输入新的校验码加载；已加载过的账号可在下拉框里一键切换。若游戏里抽了新池子或换了厨具，点击 **「重新同步存档」** 即可刷新。

### 2. 百味楼配队
* **已内置第 1 ~ 11 层全部点单数据**（保存在 `data/baiweilou_floors.json`）。
* **一键全算**：换新账号后，点击左侧 **「一键全算」**，可一次算出全部已收录楼层的推荐上阵厨师与预估总分（勾选「换厨具冲榜」可连带优化厨具）。
* **新增后续开放的楼层**（第 12 层、13 层…）：
  1. 点击 **「+ 新增楼层」**；
  2. 填写楼层名称、上阵人数、目标分；
  3. 在菜谱输入框输入菜名联想添加（或用逗号一次性粘贴多道菜名后回车）；
  4. 点击 **「保存楼层配置」** 即可持久化保存，并直接点击计算。

### 3. 每周厨神大赛 / 限时活动关
1. 每周五 13:00 新大赛开启后，点击右上角 **「刷新图鉴 & 当周厨神规则」**。
2. 切换到 **「每周厨神大赛 / 活动关」** 标签页，选择你所在的分段（如御前 / 皇城 / 省级等）或活动关。
3. 点击 **「开始计算厨神阵容」**，即可输出 3 厨 × 3 菜的精确份数分配、单价与高/中/低保过线状态。

## 命令行用法（可选）
也可以直接在终端调用核心脚本：
```bash
# 求解本周厨神大赛（规则 ID: 1=御前, 7=皇城, 8/9=活动关）
python bcjh_solver.py --token 你的校验码 --rules 1,7 --refresh

# 求解百味楼指定关卡
python baiweilou_solver.py --token 你的校验码 --dishes "香菇青菜,扬州炒饭,地三鲜,回锅肉,海鲜面" --slots 3 --target 2580 --swap-equips
```

## 自行打包 Windows `.exe`
如修改了代码想在本地重新生成绿色单文件 EXE：
```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --name "爆炒江湖配队助手" --add-data "web;web" --add-data "data/baiweilou_floors.json;data" app.py
```
打包产物位于 `dist/爆炒江湖配队助手.exe`。
